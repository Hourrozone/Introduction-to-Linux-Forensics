# 🐧 Introduction to Linux Forensics

## 📖 About This Repository

This repository documents my learning and practical exploration of **Linux Digital Forensics**, focusing on the techniques, tools, and artifacts used to investigate security incidents on Linux systems.

The lessons cover how to identify, collect, and analyze forensic evidence from Linux environments, including system logs, authentication records, file modifications, process activity, network connections, and memory images.

The goal is to build a practical understanding of Linux forensic investigations, from examining individual artifacts to understanding how different pieces of evidence can be correlated during an incident response.

## 📚 Repository Contents

The repository covers the following topics:

1. Introduction to Linux Forensics
2. Linux Forensics Artifacts
3. Linux Logging
4. Systemd Journal
5. Auditd
6. Auditd Log Review
7. File Modifications
8. Linux Bash History and Crontab
9. Linux Persistence
10. Linux Process Forensics
11. Linux Network Forensics
12. Linux Memory Image
13. Sysmon for Linux in Linux Forensics
14. Volatility 3 with Plugins

Each lesson provides relevant explanations, commands, tool usage, and practical walkthroughs to help understand the underlying forensic techniques.

## 🎯 Learning Objectives

Through these lessons, I aim to develop practical knowledge in:

- Linux forensic artifacts and evidence collection.
- Linux logging and audit analysis.
- File modification and persistence investigation.
- Bash history and scheduled task analysis.
- Process and network forensics.
- Linux memory acquisition and analysis.
- Sysmon for Linux event investigation.
- Memory forensics using Volatility 3.
